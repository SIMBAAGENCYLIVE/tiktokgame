Hébergement (Render ou Railway) :
- Type : Web Service, runtime Node.
- Build command : npm install
- Start command : node bridge.js
- Variable d'environnement : TIKTOK_USER = pseudo du compte en live (sans @)
- Le port est fourni automatiquement (variable PORT).
- Adresse à mettre dans LIVE Studio : l'URL https du service (la page est servie à la racine).
- Sur une offre gratuite, le service peut se mettre en veille quand personne ne l'utilise : prends une offre qui reste allumée.
